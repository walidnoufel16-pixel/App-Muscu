## Les fichiers
| Fichier | Contenu |
|---|---|
| `journal.md` | Une ligne par publication : date, contenu, réseaux, résultat en bref |
| `enseignements.md` | Ce qui marche, ce qui ne marche pas, règles à appliquer aux prochains packs |
| `stats/AAAA-MM-JJ.md` | Un relevé de stats complet par date |
| `semaine-N/` | Le pack de la semaine : vidéos, carrousels, `legendes.md` (calendrier + légendes), article |
| `../Plan-Editorial-Oxa-2026-11.pdf`, `../Plan-Communication-Oxa-2026-11.pdf` | Plans de fond |
| `../../outils/reseaux/` | Scripts de fabrication (plans vidéo, captures, Word des légendes) |

## Routine d'une session réseaux
1. Lire ce fichier, puis `enseignements.md`.
2. Faire le travail du jour (un pack, un relevé de stats, une analyse…).
3. Avant de finir : mettre à jour « Où en est-on », ajouter les lignes de `journal.md`,
   et noter dans `enseignements.md` toute leçon nouvelle.
4. Une session par chantier ; en ouvrir une nouvelle dès que la conversation s'allonge.
